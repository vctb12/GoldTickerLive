# See.io-inspired multi-metal chart synthesis audit

**Audit date:** 2026-08-24
**Target:** `vctb12/GoldTickerLive` at `db66de97b2`
**Production:** <https://goldtickerlive.com/tracker.html>
**Owner reference:** <https://mellow-delta-42.s4.seeiousercontent.com/#chart>

## Executive finding

GoldTickerLive already has the stronger product: bilingual/RTL behavior, explicit source and
freshness states, reference-versus-retail framing, exports, watchlists, alerts, and layered history.
The reference is materially better at one thing: its chart interaction is compact, obvious, and
metal-first.

The target should adopt that interaction without adopting the reference's unsafe history-pinning
claim or its undocumented source assumptions. The safe implementation is a normalized series and
quality layer plus a feature-gated switcher in the existing chart. Non-gold production history must
remain unavailable—not fabricated—until source terms and ingestion are approved.

## Safe scope selected

This PR implements the P0 normalized series/live-anchor work and the safe parts of the P1/P2 tracker
work. It does not enable production non-gold history, change a provider workflow, add a dependency,
alter gold maths, or touch any protected file.

## Implementation result

The safe scope is complete. Gold now renders and exports one normalized visible series, including a
provider-timestamp current anchor only when it is valid and newer; the advanced chart consumes the
same rows, removing the audited headline/chart divergence. `6M` is additive and backward-compatible.

The four-metal interaction is implemented only as an explicit localhost preview while
`METALS_PILOT_ENABLED` remains false. Silver, platinum, and palladium display a validated current
reference quote with source, provider timestamp, freshness/closed state, and a current-only warning.
They do not display fabricated history. Production history, terms confirmation for platinum and
palladium, and final flag activation remain owner decisions.
