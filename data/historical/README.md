# Historical daily XAU/USD data

`xau-usd-daily.json` in this directory is **generated by a trusted live workflow only** — do not
hand-edit.

| Field      | Value                                                                                                                  |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| Provider   | [gold-api.com](https://gold-api.com/) `/history` endpoint                                                              |
| Refresh    | `.github/workflows/historical-gold-refresh.yml` (daily ~02:45 UTC on `main`; manual `workflow_dispatch` for bootstrap) |
| Secret     | `GOLD_API_KEY` (workflow only — **never** on `pull_request` jobs)                                                      |
| Provenance | `dataOrigin: "live-provider"` + `workflow.runId` + `rawResponseSha256`                                                 |
| Consumer   | Homepage UAE historical karat chart (`src/lib/uae-historical-source.js`)                                               |

## Production file requirements

The homepage loader rejects any file that is missing:

- `dataOrigin: "live-provider"`
- `workflow.runId` from GitHub Actions
- `rawResponseSha256` and `normalizedRecordsSha256`
- matching coverage metadata

Until a successful **live** `workflow_dispatch` bootstrap commits this file, the homepage chart
shows the localized unavailable state.

## Regenerate (trusted runner only)

```bash
# GitHub Actions → Historical Gold Refresh → workflow_dispatch
# Set bootstrap_branch=true on the PR branch (one-time)
```

Local regeneration requires the API key **and** `GITHUB_RUN_ID` (not available outside Actions). Use
fixture mode for local/PR validation only:

```bash
node scripts/node/fetch-gold-api-history.mjs \
  --fixture tests/fixtures/gold-api-history/provider-response-official.json \
  --output /tmp/xau-usd-daily-fixture-check.json
```

Fixture mode **cannot** write to `data/historical/xau-usd-daily.json`.

## Provider response shape (official)

Array of `{ "day": "YYYY-MM-DD", "avg_price": number|string }` when using
`groupBy=day&aggregation=avg`.

See `https://gold-api.com/llms.txt` and run:

```bash
node scripts/node/fetch-gold-api-history.mjs --diagnose-schema
```

(on a trusted runner with `GOLD_API_KEY`)

Validation thresholds: `src/lib/gold-api-daily-history-contract.js`
